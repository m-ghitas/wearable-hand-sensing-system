# 3D model asset (not bundled)

The original V4 application expects `hand_model.glb` in this directory.

The archived prototype refers to [Emma L. D. Lieker’s anatomical hand model](https://github.com/emmalieker/anatomical-hand-model), with **CC BY-NC 4.0** attribution in `docs/ASSET_CREDITS.txt`. Check current upstream distribution and licensing before downloading or redistributing any model.

This public-repository starter intentionally **does not include** `hand_model.glb`. The renderer will not display the model until you supply an appropriately licensed model compatible with the existing bone names. The derived `hand_kinematics.json` must also be handled consistently with the upstream asset license.
